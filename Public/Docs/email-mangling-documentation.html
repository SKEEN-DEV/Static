🎯 Overview

What is Email Mangling?

Email mangling is a system that generates scrambled/obfuscated email addresses for journalist enquiries. It allows PR subscribers to reply to enquiries while protecting journalist privacy and enabling tracking.

Key Features

🔒 Protect Privacy

Hide journalist's real email from PR subscribers

📊 Enable Tracking

Embed contact ID for analytics and routing

🔄 Deterministic

Same ID always produces same result

↩️ Reversible

Can decode back to original IDs

How It Works

Example Flow:

  1. Enquiry ID: 12345, Contact ID: 678
  2. Mangle IDs: 12345 → XQiLm, 678 → gTE
  3. Generate email: rs-XQiLm.gTE@email.responsesource.com
  4. User sends reply to this scrambled address
  5. System demangled IDs and routes email to correct journalist

💡 How it works: Each digit (0-9) maps to a specific letter. This simple substitution cipher makes IDs unreadable to humans while remaining reversible.

2. Mangle Function

public static function imangle($string) {
    return str_replace(
        array_keys(self::$mangle_map), 
        array_values(self::$mangle_map), 
        $string
    );
}

// Example:
// Input:  "12345"
// Output: "XQiLm"

3. Demangle Function

public static function idemangle($string, $single = 0) {
    return DWPub_Utility::getInt(
        str_replace(
            array_values(array_map("mb_strtolower", self::$mangle_map)), 
            array_keys(self::$mangle_map), 
            mb_strtolower($string)
        ), 
        $single
    );
}

// Example:
// Input:  "XQiLm"
// Output: 12345
⚠️ Important: The demangle function is case-insensitive - both "XQiLm" and "xqilm" will decode to the same ID.

public function getPublicEmailAddress($contact_id = null, $display_real = false) {
    if($display_real)
        return $this->EmailAddress;

    $track = "";
    if($contact_id !== null) {
        $track = ".".DWPub_Utility::imangle($contact_id);
    }

        ->get($this->Territory, "UK")->obscure_sender_email_domain;

⚛️ TypeScript/React Implementation

1. Email Mangling Utility Class

Create file: src/utils/emailMangler.ts

/**
 * Email mangling utilities for ResponseSource
 * Converts numeric IDs to obfuscated email addresses and back
 */
export class EmailMangler {
  // Digit to character mapping (must match PHP implementation)
  private static readonly mangleMap: Record<string, string> = {
    '0': 'A', '1': 'X', '2': 'Q', '3': 'i', '4': 'L',
    '5': 'm', '6': 'g', '7': 'T', '8': 'E', '9': 'z'
  };

  // Reverse mapping for demangling (case-insensitive)
  private static readonly demangleMap: Record<string, string> = {
    'a': '0', 'A': '0', 'x': '1', 'X': '1',
    'q': '2', 'Q': '2', 'i': '3', 'I': '3',
    'l': '4', 'L': '4', 'm': '5', 'M': '5',
    'g': '6', 'G': '6', 't': '7', 'T': '7',
    'e': '8', 'E': '8', 'z': '9', 'Z': '9'
  };

  /**
   * Mangle a numeric ID into an encoded string
   * @example EmailMangler.mangle(12345) // Returns "XQiLm"
   */
  static mangle(id: number | string): string {
    const idString = id.toString();
    return idString.split('')
      .map(char => this.mangleMap[char] || char)
      .join('');
  }

  /**
   * Demangle an encoded string back to a numeric ID
   * @example EmailMangler.demangle('XQiLm') // Returns 12345
   */
  static demangle(mangled: string): number {
    const demangled = mangled.split('')
      .map(char => this.demangleMap[char] || char)
      .join('');
    return parseInt(demangled, 10) || 0;
  }

  /**
   * Generate a public (scrambled) email address
   * @example EmailMangler.getPublicEmail(12345, 678)
   * // Returns "rs-XQiLm.gTE@email.responsesource.com"
   */
  static getPublicEmail(
    enquiryId: number, 
    contactId?: number, 
    domain: string = 'email.responsesource.com'
  ): string {
    const mangledId = this.mangle(enquiryId);
    const trackingPart = contactId ? `.${this.mangle(contactId)}` : '';
    return `rs-${mangledId}${trackingPart}@${domain}`;
  }

  /**
   * Parse a public email address to extract enquiry and contact IDs
   * @example EmailMangler.parsePublicEmail('rs-XQiLm.gTE@email.responsesource.com')
   * // Returns { enquiryId: 12345, contactId: 678 }
   */
  static parsePublicEmail(email: string) {
    const match = email.match(/^rs-([A-Za-z]+)(?:\.([A-Za-z]+))?@/);
    if (!match) return null;

    const enquiryId = this.demangle(match[1]);
    const contactId = match[2] ? this.demangle(match[2]) : undefined;

    return { enquiryId, contactId };
  }
}

2. Usage Examples

import { EmailMangler } from '@/utils/emailMangler';

// Generate scrambled email
const email = EmailMangler.getPublicEmail(12345, 678);
console.log(email); 
// Output: "rs-XQiLm.gTE@email.responsesource.com"

// Parse scrambled email
const parsed = EmailMangler.parsePublicEmail('rs-XQiLm.gTE@email.responsesource.com');
console.log(parsed); 
// Output: { enquiryId: 12345, contactId: 678 }

// Mangle/demangle IDs directly
console.log(EmailMangler.mangle(12345));    // "XQiLm"
console.log(EmailMangler.demangle('XQiLm')); // 12345

Option 1: Simple mailto Link

⏱️ 5 minutes

Best For: MVP, quick launch, users who prefer their email client

}

  • Works immediately

❌ Cons

  • Can't customize email content

Option 2: Enhanced mailto with Pre-fill

⏱️ 10 minutes ⭐ RECOMMENDED FOR MVP

Best For: Better UX without backend work

React Component

export function EnhancedReplyButton({ 
  enquiryId, 
  contactId, 
  enquiryTitle,
  companyName 
}: EnhancedReplyButtonProps) {
  const scrambledEmail = EmailMangler.getPublicEmail(enquiryId, contactId);
  
  // Pre-fill subject line
  const subject = encodeURIComponent(`Re: ${enquiryTitle}`);
  
  // Pre-fill email body with template
  const body = encodeURIComponent(
    `Hi,\n\n` +
    `I'm reaching out regarding your enquiry: "${enquiryTitle}"\n\n` +
    `[Your message here]\n\n` +
    `Best regards,\n` +
    `${companyName || '[Your Company]'}`
  );
  
  const mailtoUrl = `mailto:${scrambledEmail}?subject=${subject}&body=${body}`;

  return (
    <a 
      href={mailtoUrl}
      className="btn btn-primary"
    >
      <MailIcon className="w-4 h-4 mr-2" />
      Reply via Email
    </a>
  );
}

Option 4: Hybrid Approach

⏱️ 1-2 hours ⭐ RECOMMENDED FOR PRODUCTION

Best For: Flexibility, phased rollout, user choice

How It Works

  • Always show mailto option (guaranteed to work)
  • Optionally show in-app form (can be enabled via feature flag)
  • Users choose their preferred method
  • Gradual rollout via feature flags (10% → 50% → 100%)
export function HybridReplyButton({ 
  enquiryId, 
  contactId, 
  enquiryTitle,

🧪 Testing

Unit Tests (TypeScript)

describe('EmailMangler', () => {
  describe('mangle', () => {
    it('should mangle numeric IDs correctly', () => {
      expect(EmailMangler.mangle(12345)).toBe('XQiLm');
      expect(EmailMangler.mangle('678')).toBe('gTE');
      expect(EmailMangler.mangle(0)).toBe('A');
    });
  });

  describe('demangle', () => {
    it('should demangle strings correctly', () => {
      expect(EmailMangler.demangle('XQiLm')).toBe(12345);
      expect(EmailMangler.demangle('gTE')).toBe(678);
      expect(EmailMangler.demangle('A')).toBe(0);
    });

    it('should be case-insensitive', () => {
      expect(EmailMangler.demangle('xqilm')).toBe(12345);
      expect(EmailMangler.demangle('XQILM')).toBe(12345);
    });
  });

  describe('getPublicEmail', () => {
    it('should generate correct email format', () => {
      const email = EmailMangler.getPublicEmail(12345, 678);
      expect(email).toBe('rs-XQiLm.gTE@email.responsesource.com');
    });

    it('should work without contact ID', () => {
      const email = EmailMangler.getPublicEmail(12345);
      expect(email).toBe('rs-XQiLm@email.responsesource.com');
    });
  });

  describe('parsePublicEmail', () => {
    it('should parse email with contact ID', () => {
      const result = EmailMangler.parsePublicEmail(
        'rs-XQiLm.gTE@email.responsesource.com'
      );
      expect(result).toEqual({ enquiryId: 12345, contactId: 678 });
    });

    it('should return null for invalid email', () => {
      const result = EmailMangler.parsePublicEmail('invalid@email.com');
      expect(result).toBeNull();
    });
  });

  describe('round-trip', () => {
    it('should maintain data integrity', () => {
      const originalId = 98765;
      const originalContact = 4321;
      
      const email = EmailMangler.getPublicEmail(originalId, originalContact);
      const parsed = EmailMangler.parsePublicEmail(email);
      
      expect(parsed?.enquiryId).toBe(originalId);
      expect(parsed?.contactId).toBe(originalContact);
    });
  });
});

⚠️ Common Pitfalls

  1. Case sensitivity: PHP idemangle is case-insensitive, ensure TypeScript version handles both cases
  2. Non-numeric characters: Both implementations only mangle digits, other characters pass through unchanged
  3. Null/undefined handling: TypeScript version should gracefully handle invalid input
  4. Domain configuration: Ensure domain matches your environment (dev/staging/prod)
  5. Permissions: Respect "view real email" privilege - don't show scrambled emails to authorized users
